# Модель данных АИС «Уют»

Основные связи (логическая ERD):

- `Клиенты` 1—N `Бронирования` по `ID_Клиента`.
- `Номера` 1—N `Бронирования` по `ID_Номера`.
- `Бронирования` 1—N `Счета` и `Платежи`.
- `Бронирования` N—N `Услуги` через `Бронирование_Услуги`.
- `Клиенты` N—N `Номера` через `Избранное`.
- `Клиенты` 1—N `Отзывы`; отзыв может ссылаться на бронирование.
- `Промокоды` связаны с клиентами и бронированиями через `Использованные_промокоды`.

Физическая схема и история изменений находятся в `migrations/versions/`.
