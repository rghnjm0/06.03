# Развёртывание

1. Используйте поддерживаемую версию Python и отдельное виртуальное окружение.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Задайте `UYUT_ENV=production`, уникальный `UYUT_SECRET_KEY` и пароль bootstrap-администратора до первого запуска.
4. Настройте HTTPS на reverse-proxy. Не доверяйте `X-Forwarded-For`, пока не настроен список доверенных прокси.
5. Размещайте SQLite и резервные копии вне публичного web-root; ограничьте права доступа к файлам.
6. Перед обновлением создайте резервную копию БД. Применяйте миграции Alembic и проверяйте `/healthz`.
7. Настройте расписание `python backup_db.py` и регулярно проверяйте возможность восстановления.
8. Для нескольких серверов используйте общий backend для rate-limit; SQLite-лимитер рассчитан на один хост.
