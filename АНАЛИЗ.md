## ЧАСТЬ 1. КРИТИЧНЫЕ НАХОДКИ (обязательно)

### 1.1. Глобальный rate-limit входа
- **Файл:** `routes/account.py`, функция `login()`.
- **Проблема:** `client_ip = 'account'` — заглушка. Все попытки входа привязаны к одному идентификатору. Один атакующий блокирует вход всем пользователям на 15 минут.
- **Что делать:** заменить на реальный IP (`request.remote_addr`) **или** на комбинацию `identifier + IP` с учётом `X-Forwarded-For` (только от доверенного прокси). Не использовать одну константу.
- **Трудозатраты:** S.
- **Что даёт:** закрывает DoS на аутентификацию, исключает критическую находку A07.

### 1.2. Мёртвый legacy-модуль с ImportError
- **Файл:** `routes/auth.py`.
- **Проблема:** не импортируется, содержит `from security import password_matches, hash_password, validate_password` — этих имён в `security.py` нет. При случайном импорте приложение падает.
- **Что делать:** удалить файл. Проверить `grep -rn "routes.auth\|from routes import auth"`.
- **Трудозатраты:** S.
- **Что даёт:** убирает риск падения, чистит A06/A08.

### 1.3. Двойные миграции: Alembic + `ensure_*_schema()`
- **Файлы:** `app.py` (вызовы `ensure_extended_schema`, `ensure_payment_schema`, `ensure_features_schema`), `hotel_logic.py`, `routes/features.py`, `routes/payments.py`.
- **Проблема:** схема поддерживается параллельно двумя механизмами. Alembic-версия и фактическая схема могут расходиться.
- **Что делать:**
  1. Удалить вызовы `ensure_*_schema()` из `app.py`.
  2. Перенести содержимое `ensure_extra_rooms` в Alembic-ревизию.
  3. Добавить `alembic upgrade head` при старте приложения (или явным шагом деплоя).
- **Трудозатраты:** M.
- **Что даёт:** закрывает A08, устраняет рассинхрон.

### 1.4. Пароль bootstrap-администратора в stdout
- **Файл:** `db.py`, функция `add_admin_user()`.
- **Проблема:** `print(password)` — попадёт в systemd journal / Docker logs.
- **Что делать:** записывать в файл с правами 600 (например `secrets/admin_bootstrap.txt`) или отдавать через ENV, если задан. Убрать печать.
- **Трудозатраты:** S.
- **Что даёт:** закрывает A02, A04.

### 1.5. Rate-limit `/search` по X-Forwarded-For
- **Файл:** `app.py`, `rate_limit_search()`.
- **Проблема:** `ip = (request.headers.get("X-Forwarded-For") or ...)` — заголовок подделывается клиентом. Атакующий обходит лимит, подставляя разные XFF.
- **Что делать:** использовать `request.remote_addr`. Если прокси — доверять XFF только по списку доверенных IP (например через `ProxyFix` с явным `trusted_proxies`).
- **Трудозатраты:** S.
- **Что даёт:** rate-limit становится рабочим.
